# CSE 210 - Week 01 C# Programming Exercises

This folder contains five separate .NET console projects based on the BYU-Idaho CSE 210 Week 01 exercise instructions.

## Projects
1. Exercise1_InputOutput - asks for first and last name and displays them in the requested format.
2. Exercise2_IfStatements - calculates a letter grade, grade sign, and pass/fail message.
3. Exercise3_Loops - Guess My Number game using a random number from 1 to 100, with guess count and replay.
4. Exercise4_ListsAndGenerics - collects numbers until 0, then calculates sum, average, largest, smallest positive, and sorted list.
5. Exercise5_Functions - uses the five required functions to greet the user and square their favorite number.

## Run a project
Open a project folder in VS Code, then run this in its terminal:

    dotnet run

Each project targets .NET 10.0. If your installed SDK is older, change `<TargetFramework>net10.0</TargetFramework>` in that project's `.csproj` file to a framework you have installed.

## Important
These are worked examples for learning and practice. Read each `Program.cs`, run it, and make sure you understand how it works. Adjust the code to match your instructor's directions and your own approach before submitting coursework.
